# CS2026-Hackerton

2026년 10월 학교 해커톤 사전 준비용 레포지토리입니다.

## 목표

- 해커톤 당일 공개되는 주제를 빠르게 분석하고 핵심 문제를 정확히 찌르는 결과물을 만든다.
- AI 모델, 외부 API, 자동화 도구를 제한 없이 적극 활용한다.
- 다른 팀이 잘 다루지 않을 가능성이 높은 영역(운영/연동/자동화/완성도)을 선점해 차별화한다.

## 팀 구성 (3인 개발)

- **기획/도메인 담당 (1인)**: 문제 정의, 사용자 시나리오, 데모 스토리라인 정리
- **제품/프론트 담당 (1인)**: 사용자 흐름, 인터페이스, 시연 품질 책임
- **플랫폼/백엔드 담당 (1인)**: AI/외부 API 연동, 데이터 흐름, 배포/운영 안정화

## 사전 준비 범위

주제가 미정이므로, 재사용 가능한 공통 기반을 미리 준비한다.

- 빠른 프로토타이핑용 템플릿/보일러플레이트 정리
- AI 모델 선택 기준(속도/비용/품질)과 교체 전략 수립
- 외부 API 연동 패턴(인증, 에러 처리, 재시도, 로깅) 표준화
- 데모 운영 체크리스트(실패 대비 시나리오, 폴백 전략) 준비

## 대회 당일 운영 원칙

1. 주제 공개 후 30~60분 내 문제 재정의와 MVP 범위를 확정한다.
2. 핵심 기능을 먼저 구현하고, 차별화 기능은 리스크가 낮은 순서로 추가한다.
3. AI/API 의존 기능에는 항상 대체 경로(폴백)를 둔다.
4. 발표 직전에는 기능 추가를 멈추고 데모 안정화에 집중한다.
