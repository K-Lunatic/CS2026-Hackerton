# 핵심 학습 흐름

게시판, 시간표, 강의실 시험정보를 자주 사용하는 사용자를 위한 우선순위 규칙이다.

## 1. 게시판 흐름

1. 사용자가 게시판 이름·키워드·기간 중 말한 조건만 사용한다.
2. 현재 학교의 게시판 목록에서 이름을 확인한다. 비슷한 이름이 여러 개면 후보를 보여주고
   하나를 임의로 고르지 않는다.
3. 목록을 최신순으로 읽고, `articleId`로 중복을 제거한다.
4. 고정 공지와 일반 글을 구분한다. `onlyNew`가 켜져 있으면 화면에 새 글로 표시된 항목만
   반환한다.
5. 키워드가 있으면 제목과 본문에 실제로 등장한 단어만 `matchedKeywords`에 기록한다.
6. 본문을 열 수 없는 글은 제목만으로 성공 처리하지 않고 `partial: true`로 남긴다.

게시판 기본 추천값은 `maxItems: 20`, `includeComments: false`, 최근 7일이다. 사용자가
“전부”라고 말해도 무한 수집하지 않고 기간이나 최대 개수를 먼저 확인한다.

## 2. 시간표 흐름

1. 현재 선택된 학기와 시간표 이름을 먼저 읽는다.
2. 시간표 블록에서 과목명·교수·학점·요일·시작/종료 시각·강의실을 정규화한다.
3. 동일 과목이 여러 분반으로 보이면 분반 정보가 화면에 있을 때만 분리한다.
4. 겹치는 요일·시간을 계산해 `conflicts`에 표시한다. 단순 조회 요청으로는 수정하지 않는다.
5. 강의실 시험정보를 요청하면 이 결과의 `courseId`·과목명·교수명을 다음 조회의 기준으로
   사용한다. 과목명을 임의로 유사 매칭하지 않는다.

## 3. 시험정보 흐름

1. 시간표에서 현재 학기 과목을 가져온 뒤 사용자가 지정한 과목만 우선한다.
2. 각 과목의 강의실에서 시험 관련 항목을 제목·본문·태그 기준으로 찾는다.
3. 시험일, 시간, 장소, 형식, 범위, 준비물, 유의사항을 각각 분리해 기록한다.
4. 교수·강의실 공지처럼 공식 출처인 내용은 `OFFICIAL`, 수강생이 남긴 시험 후기·팁은
   `STUDENT_REPORT`로 표시한다.
5. 서로 충돌하는 날짜나 범위가 있으면 최신 게시 시각과 URL을 함께 보여주고 자동으로 하나를
   선택하지 않는다.
6. 정보가 없거나 로그인 만료로 확인하지 못한 경우 “없음”과 “확인 불가”를 구분한다.

시험정보 결과 예시:

```json
{
  "courseName": "자료구조",
  "examInfo": "중간고사",
  "examDate": "2026-10-21",
  "examTime": "10:00-11:30",
  "examLocation": "공학관 301호",
  "examFormat": "대면 필기",
  "examRange": "트리부터 해시까지",
  "sourceType": "OFFICIAL",
  "publishedAt": "2026-10-06T09:10:00+09:00",
  "url": "https://everytime.kr/..."
}
```

## 공통 품질 규칙

- 현재 화면에서 확인한 값과 Skill의 추론을 분리한다.
- 게시판 글·시험 후기는 공식 학사 정보처럼 표현하지 않는다.
- 한 과목을 여러 이름으로 발견해도 확인 근거가 없으면 합치지 않는다.
- 부분 수집은 성공으로 포장하지 않고 `partial: true`와 누락 이유를 함께 반환한다.

## 4. 강의평 활용

`--reviews <courseId> --purpose study|enrollment`의 근거 색인을 사용한다.
초기 설정은 최신 20개 이하의 후기와 서비스의 전체 집계(과제·조모임·성적·출결·시험)를 저장한다.
집계의 응답 수와 읽은 후기의 표본 수는 다르다. 점수만으로 과목을 추천하지 않는다.

- `study`: 시험 방식·공부 방법·평가·과제 근거를 읽고 현재 강의자료/공지와 대조한다.
  후기에 적힌 객관식 수, 기출 반복, 공부 범위는 해당 후기 학기의 경험이다. 현재 시험의
  확정 형식·일정·범위처럼 안내하지 않는다. 시험 유형을 찾지 못하면 확인 불가로 둔다.
- `enrollment`: 동일 과목이라도 교수가 다르면 따로 비교한다. 과제·조모임·출결·성적 집계의
  각 선택지와 응답 수를 보여주고 사용자의 시간·학습 목적에 맞춰 설명한다. 실제 학기 개설
  여부·시간은 `--search-subjects`로 확인한다. 수강 가능 학년·정원·졸업 인정 여부는 이 자료만으로 확정하지 않는다.
- `topics`는 키워드 색인이다. `matchedTerms`가 있어도 문장의 긍정/부정을 보장하지 않는다.
  원문 전체와 후기 연도/학기를 읽은 뒤 해석하고, 설명의 근거로 `reviewId`와 원문 URL을 보존한다.
- 서로 다른 후기는 다수결로 사실로 바꾸지 않는다. 교수·학기별 변화 가능성을 알리고,
  표본이 제한된 경우 전체 수강생의 합의인 것처럼 표현하지 않는다.
