# 공용 학습 프로필

## 목적

학습 프로필은 같은 기기에서 여러 채팅이 함께 쓰는 작은 메타데이터다. 사용자의 학습 방식을 보관해 다음 채팅에서도 설명 깊이·문제 형식·복습 방식을 이어 간다. 원본 노트, 녹음, 전사, TLS 자격증명은 프로필에 넣지 않는다.

## 먼저 묻는 범위

새 개념·자료 분석을 시작하기 전에는 다음 순서로 확인한다.

1. TLS에서 동기화된 수업자료와 저장된 분석·풀이 기록을 확인해도 되는지 묻는다.
2. Notability를 사용할 때는 최근 노트 목록을 확인해도 되는지 따로 묻는다.
3. 특정 노트를 고른 뒤 필기·녹음·전사를 읽어도 되는지 다시 묻는다.

동의 전에는 원문 추출·전사 분석·학습 스타일 확정을 하지 않는다. 여러 노트가 맞으면 사용자에게 선택받고, 선택하지 않은 노트는 읽지 않는다.

## 저장 필드

- learningStyle: 사용자가 확인한 방식. notability, typed_notes, handwritten_notes, lecture_only, mixed, unknown 중 하나.
- preferredSources: 사용자가 복습에 실제로 쓰는 자료.
- availableSources: 현재 접근 가능한 자료 범위의 요약.
- skillInventory: 현재 학습에 관련된 기능의 이름과 설명.
- consents: sourceAnalysis, notabilityMetadata, notabilityContent 동의 여부.
- evidence: 사용자가 직접 말한 근거를 짧게만 저장한다. 활동에서 추정한 내용은 근거로 저장하지 않는다.

저장·조회는 learning-profile 명령을 사용한다. 변경은 사용자가 답한 필드만 병합하고 이전 프로필을 덮어쓰지 않는다. 분석 결과는 별도의 append-only analysis history에서 재사용한다.

## 학습 방식별 적용

- Notability: 전사 시각·필기 위치를 근거로 짧은 회상 문제를 만든다.
- 입력 노트: 구조화 요약, 비교표, 체크리스트를 먼저 준다.
- 손필기: 페이지·키워드 중심의 짧은 회상과 빈칸 문제를 우선한다.
- 듣고 끝남: 강의 직후 3~5문항으로 즉시 회상하게 한다.
- 혼합: 과목별로 선호 방식을 따로 저장하고 해당 과목 설정을 우선한다.

## 공개 범위

사용 가능한 기능은 TLS, 에타 참고, 읽을 수 있는 문서, 저장된 학습 기록, 동의한 Notability, 학습 팩처럼 결과 중심으로 보여준다. 내부 경로, 쿠키, 토큰, 비밀번호, 무관한 스킬 전체 목록은 공개하지 않는다.

다른 기기에서는 사용자가 학습 팩을 직접 내보내고 가져온다. 학습 팩에도 원본 파일·자격증명·Notability 원문은 포함하지 않는다.
